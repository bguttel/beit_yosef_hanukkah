# השמן השמיני

אפליקציית ווב בעברית על קושיית הבית יוסף: מדוע חוגגים חנוכה שמונה ימים אם בפך היה שמן ליום אחד והנס היה לכאורה רק שבעה ימים?

## הרצה מקומית

```powershell
python -m http.server 8000
```

לאחר מכן פותחים `http://localhost:8000`.

האפליקציה סטטית ואינה דורשת תהליך build או תלויות. היא כוללת מצב גילוי תירוצים, משחק “אמת או המצאה”, שמירת ניקוד מקומית והתאמה מלאה למובייל.
